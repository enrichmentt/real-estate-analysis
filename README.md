# Regional Household Consumption Analysis

Учебный проект по кластеризации регионов России и прогнозированию фактического конечного потребления домашних хозяйств на душу населения по данным Росстата за **2000–2023 годы**.

## Что сделано

- выполнены очистка данных и преобразование из широкого формата в длинный;
- исключены агрегированные записи и регионы с неполной историей;
- для каждого региона рассчитаны шесть признаков уровня, роста и волатильности;
- проведена кластеризация K-means с сравнением решений для 2–4 кластеров;
- выбраны Республика Коми, Курская область и Красноярский край для детального анализа;
- построены HP-тренды, проведены ADF-тесты и построены графики ACF / PACF;
- реализованы наивный прогноз, Holt и ARIMA;
- выполнено хронологическое holdout-разбиение: обучение — 2000–2018 годы, тест — 2019–2023 годы;
- рассчитаны RMSE и MAPE, выполнен rolling forecast с переобучением моделей;
- построены прогнозы на 2024–2026 годы и проанализированы основные ошибки;
- сформулированы рекомендации для каждого выбранного региона.

Все ячейки ноутбука выполнены: в файле сохранены графики, таблицы и результаты расчётов. Дополнительно подготовлен PDF-отчёт с выводами по каждому этапу.

## Результаты

Для анализа использованы **79 регионов** с полными рядами. Наилучший silhouette score получен для **4 кластеров** — **0,3354**. На тестовой выборке ARIMA показала минимальный RMSE для всех трёх выбранных регионов.

| Регион | Лучшая модель | RMSE, руб. | MAPE | Прогноз на 2026 год, руб. |
|---|---|---:|---:|---:|
| Республика Коми | ARIMA | 57 512 | 8,166% | 738 676 |
| Курская область | ARIMA | 23 049 | 4,761% | 622 462 |
| Красноярский край | ARIMA | 49 037 | 7,286% | 668 443 |

Показатель выражен в текущих рыночных ценах, поэтому прогнозы отражают номинальную динамику и не должны напрямую интерпретироваться как изменение реального уровня жизни.

## Запуск в виртуальном окружении

Рекомендуется Python 3.12.

Создайте виртуальное окружение в корне проекта:

```bash
python -m venv .venv
```

Активируйте его в Windows:

```bash
.venv\Scripts\activate
```

Или в macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимости и запустите полный анализ:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src/time_series_project.py
```

Для повторного выполнения ноутбука из командной строки:

```bash
python -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=300 notebooks/regional_consumption_analysis.ipynb
```

Для пересборки PDF-отчёта:

```bash
python scripts/build_report.py
```

Датасет уже находится в каталоге `data`, поэтому отдельная загрузка не требуется. Ноутбук и скрипты нужно запускать из корня проекта, чтобы относительные пути работали корректно.
